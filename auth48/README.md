# AUTH48 edits to RFC 9942

This directory tracks edits made by the authors of RFC 9942
(`draft-ietf-cose-merkle-tree-proofs`) during the AUTH48 review stage.

## Files

- `rfc9942.xml` — the RFC Editor's authored XML
  (https://www.rfc-editor.org/authors/rfc9942.xml) with author
  edits applied. New `[authors]` annotation blocks document each
  change in-place using the same convention as the RFC Editor's
  `[rfced]` queries.

## Workflow

1. Download the latest RFC Editor XML from
   `https://www.rfc-editor.org/authors/rfc9942.xml`.
2. Apply edits in this directory.
3. Send the modified XML back to the RFC Editor as part of the
   AUTH48 response.
4. Commit the modified XML so the working group has a record of
   every author-stage change.

After publication this directory can be removed.
